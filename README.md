## How I like to build

- **Reproducible:** configuration, datasets, model artifacts, and evaluation steps should be traceable.
- **Inspectable:** important decisions should be explainable instead of hidden behind a black box.
- **Boundary-aware:** demos, synthetic data, development authentication, and production guarantees should be labelled honestly.
- **Maintainable:** typed interfaces, validation, tests, documentation, CI, and operational notes are part of the product.
- **Product-minded:** architecture matters, but the final workflow still has to be understandable and useful to the person using it.
